# 彩虹跑马灯边界线

这是一个 CC GUI Tier-0 声明式插件，在对话运行（AI 生成/回复）期间为聊天输入框及上方会话页签（Tab）显示流动彩虹跑马灯边界线，并在后台会话生成完成未查看时提供醒目的绿色呼吸边框提醒；空闲查看后自动恢复常规外观。

插件不申请额外权限，也不包含 JavaScript。

## 特性

- 🌈 **动态触发跑马灯**：会话运行中（AI 正在生成回复）展示流动彩虹跑马灯（输入框 2px、会话页签 1px 精细内描边），空闲状态无侵入恢复原生边框。
- 🟢 **会话完成未读提醒**：后台会话执行完毕后，对应会话页签呈现 1px 绿色边框与温和的呼吸微光，一眼即可获知哪个后台任务已完成，点击切入后自动清除。
- ⚡ **零 JS 开销**：Tier-0 声明式设计，纯 GPU 加速 CSS 动画，无额外运行时消耗。
- 🔒 **纯安全**：0 权限申请，无网络请求，无脚本审计负担。

## 安装

在 CC GUI 应用内的插件市场搜索「彩虹跑马灯边界线」一键安装。

## 手动安装（本地开发）

把整个文件夹放到 CC GUI 的本地插件目录（`设置 → 插件 → 打开插件目录`），重载即可。

## 发版

```bash
git tag 1.2.0 && git push origin 1.2.0
```

推送与 `manifest.json` 的 `version` 完全一致的 tag（无 `v` 前缀）后，GitHub Action 会自动把
`manifest.json` / `styles.css` / `checksums.txt` 附加到该 tag 的 Release。
